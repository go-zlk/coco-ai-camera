# Coco / Kui Q 版角色

最终资产采用当前页面已有的原生 SVG 插画方式。内置 image_gen 的两次角色生成请求均返回网络错误，未生成可用图片；没有使用 CLI/API 备用方式。以下角色由项目代码绘制，不宣称为成功生成的 AI 位图。

## 作图规格

大头、小身体、圆眼睛、短爪和蓬松尾巴，统一暖色柔和阴影、透明背景，不包含人物、房间、文字或饰品。Coco 保留灰白毛色与脸部灰色斑块，Kui 保留奶油橘白毛色。依据已有注册照片设计，参考照片只存于被忽略的 local/avatar-references，不提交真实照片。

- `web/characters/coco-chibi-v1.svg`：Coco 灰白角色。
- `web/characters/kui-chibi-v1.svg`：Kui 橘白角色。

网站复制到 source/images/coco。SVG 无外部链接或脚本，作为 img 使用。PNG 渲染预览仅用于本地视觉检查，位于 local/avatar-preview，不是网页依赖。

## 展示规则

“家里的伙伴”展示两个角色。实时主场景只有在 live、在线、新鲜且身份为 matched/held 时才切换；待确认、未知名称、连接失败、离线或模拟模式继续使用通用形象。映射限定注册名 Coco/Kui，不使用轨迹 ID，也不将用户名称拼接为资源路径。加载失败回退通用形象。

活动时轻微晃动，休息时轻微呼吸；这不是多姿势精灵图或睡眠识别。减少动态效果设置关闭动画。Q 版图仅用于展示，不加入身份库、不作为训练样本、不影响身体特征匹配。
