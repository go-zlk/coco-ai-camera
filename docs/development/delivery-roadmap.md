# 近期交付顺序

产品目标：在工作间隙可靠查看家中单猫的可见、活动和安静状态，回顾当天记录。Physical Context Engine 保留为底层长期能力，不同时扩展姿态教练或全屋自动化。

| 阶段 | 交付 | 当前状态 | 进入下一阶段的门槛 |
|---|---|---|---|
| 体验收口 | 网站看板、观察信号、时间线、最近动态、空/异常状态 | 代码与渲染契约通过，新版视觉受浏览器策略阻止尚待复核 | 桌面、手机、深色实际检查，演示/真实明确可分 |
| 真实链路 | 固定摄像头、C++ 状态、SQLite、网页、断流恢复 | 验收工具与步骤就绪，尚未连接板子 | 实机前台 2 小时、断流、重启保存通过 |
| 准确性 | 遮挡、转身、暗光、远处、抱猫与双猫样例 | 待用户真实输入 | 可复现标注与错误分类，不以演示声称精度 |
| 日常运行 | 后台运行、12 小时与一天检查 | 用户服务模板就绪，未安装启用 | 系统与设备实测，数据和日志可控 |
| 个人远程 | 受保护的账户/设备查询 | 未部署 | 明确私有访问或账户网关；不公开无认证 API |
| 小范围试用 | 3～5 位真实用户 | 未开始 | 前述可靠性门槛通过，再评估安装成本和持续使用 |

每轮保留代码提交、可重复步骤和验收证据。设备账号、IP、原始媒体与运行报告均不提交。没有真实运行或标注结果时不标记准确率、长期稳定性或产品验收通过。

明确后置：新摄像头适配、云台、多摄像头、持久宠物身份、精确睡眠/情绪/健康判断、LLM 总结、智能家居控制、原生手机/手表客户端与收费体系。

当前需要用户确认的下一步仅为板子是否在线及首轮视频源；远程托管方案等真实链路通过再拍板。
